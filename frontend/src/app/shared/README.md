# Shared Directory

## Purpose

This directory contains shared code, utilities, interfaces, and constants used across the application.

## Structure

- Interfaces and types for TypeScript
- Utility functions and helpers
- Constants and enums
- Shared services (if not in services directory)

## Usage

- Define interfaces for API responses
- Create utility functions for common operations
- Store application-wide constants
- Share code between components and services

## Example Structure

```
shared/
  interfaces/
    user.interface.ts
    api-response.interface.ts
  utils/
    date.utils.ts
    validation.utils.ts
  constants/
    api.constants.ts
    app.constants.ts
```
